1. Introduction

Welcome to GoalWear — a premium football gear e-commerce theme built with modern web technologies. This theme is production-ready and includes everything you need to launch a professional online store.

What's Included

  • Full Next.js 16 + React 19 source code
  • Supabase database & authentication integration
  • Stripe payment gateway
  • Complete admin panel with 12 sections
  • User account system
  • Product variants (Home/Away/Third/Goalkeeper)
  • Order management system
  • Coupon & discount system
  • SEO optimized (sitemap, robots, metadata)
  • Mobile-first responsive design
  • Dark & Light mode

✅ Installation complete! Now proceed to Supabase setup.

4. Supabase Setup

4.1 Create Project

  1. Go to supabase.com/dashboard
  2. Click "New project"
  3. Name: goalwear (or your brand)
  4. Database Password: Create a strong password
  5. Region: Choose closest to your users
  6. Click "Create new project"
  7. Wait 1-2 minutes for setup

4.2 Get API Keys

In your Supabase project:

  1. Go to Settings → API
  2. Copy these three values:
KeyLooks Like
Project URLhttps://xxxxx.supabase.co
anon public keyeyJhbGc...
service_role keyeyJhbGc... (click Reveal)
⚠️ Service Role Key is sensitive. Never share it publicly or commit it to Git.

4.3 Enable Email Auth

  1. Go to Authentication → Providers
  2. Enable Email provider
  3. Set Confirm email: ON for production, OFF for testing
  4. Go to Authentication → URL Configuration
  5. Site URL: http://localhost:3000
  6. Redirect URLs:
    • http://localhost:3000/**
    • http://localhost:3000/reset-password
    • http://localhost:3000/auth/callback

5. Stripe Setup

5.1 Create Account

  1. Go to dashboard.stripe.com
  2. Sign up or log in
  3. Stay in Test mode initially

5.2 Get API Keys

  1. Go to Developers → API keys
  2. Copy the following:
KeyLooks Like
Publishable keypk_test_...
Secret keysk_test_... (click Reveal)

5.3 Enable Payment Methods

  1. Go to Settings → Payment methods
  2. Enable Cards (required)
  3. Click Save

6. Environment Variables

Open .env.local in your code editor and fill in the values:

# ---------- Supabase ----------
NEXT_PUBLIC_SUPABASE_URL=https://your-project.supabase.co
NEXT_PUBLIC_SUPABASE_ANON_KEY=eyJhbGc...
SUPABASE_SERVICE_ROLE_KEY=eyJhbGc...

# ---------- Stripe ----------
STRIPE_SECRET_KEY=sk_test_...
NEXT_PUBLIC_STRIPE_PUBLISHABLE_KEY=pk_test_...

# ---------- Admin ----------
ADMIN_EMAIL=admin@yourstore.com
ADMIN_PASSWORD=ChangeThisStrongPassword123!
ADMIN_SESSION_SECRET=your-random-64-character-string

# ---------- Site ----------
NEXT_PUBLIC_SITE_URL=http://127.0.0.1:3000

Generate Admin Session Secret

Run this in your terminal:

node -e "console.log(require('crypto').randomBytes(32).toString('hex'))"

Copy the 64-character output to ADMIN_SESSION_SECRET.

⚠️ Choose a strong password for ADMIN_PASSWORD. This is your admin panel login.

7. Database Setup

In Supabase Dashboard, go to SQL Editor → New query, then paste and run this SQL:

-- ============================================
-- GOALWEAR DATABASE SCHEMA
-- ============================================

-- 1. PRODUCTS TABLE
CREATE TABLE IF NOT EXISTS products (
  id BIGINT PRIMARY KEY,
  name TEXT NOT NULL,
  category TEXT NOT NULL,
  sub_category TEXT,
  brand TEXT,
  team TEXT,
  type TEXT,
  price NUMERIC(10, 2) NOT NULL,
  image_url TEXT,
  images JSONB DEFAULT '[]'::jsonb,
  rating NUMERIC(2, 1) DEFAULT 0,
  reviews_count INTEGER DEFAULT 0,
  description TEXT,
  sizes JSONB DEFAULT '[]'::jsonb,
  reviews JSONB DEFAULT '[]'::jsonb,
  stock INTEGER DEFAULT 0,
  colors JSONB DEFAULT '[]'::jsonb,
  season TEXT,
  highlights JSONB DEFAULT '[]'::jsonb,
  specifications JSONB DEFAULT '[]'::jsonb,
  custom_fields JSONB DEFAULT '[]'::jsonb,
  kit_type TEXT,
  player_name TEXT,
  player_number INTEGER,
  is_player_edition BOOLEAN DEFAULT FALSE,
  sleeve_type TEXT,
  collar_type TEXT,
  fit_type TEXT,
  sponsor TEXT,
  surface TEXT,
  play_style TEXT,
  boot_height TEXT,
  weight_grams INTEGER,
  upper_material TEXT,
  soleplate TEXT,
  stud_type TEXT,
  closure_type TEXT,
  collection TEXT,
  release_year INTEGER,
  created_at TIMESTAMPTZ DEFAULT NOW(),
  updated_at TIMESTAMPTZ DEFAULT NOW()
);

-- 2. ORDERS TABLE
CREATE TABLE IF NOT EXISTS orders (
  id TEXT PRIMARY KEY,
  user_id TEXT,
  items JSONB NOT NULL,
  total NUMERIC(10, 2) NOT NULL,
  status TEXT DEFAULT 'Processing',
  customer_info JSONB NOT NULL,
  payment_method TEXT,
  stripe_session_id TEXT,
  created_at TIMESTAMPTZ DEFAULT NOW(),
  updated_at TIMESTAMPTZ DEFAULT NOW()
);

-- 3. ADDRESSES TABLE
CREATE TABLE IF NOT EXISTS addresses (
  id TEXT PRIMARY KEY,
  user_id TEXT NOT NULL,
  label TEXT NOT NULL,
  name TEXT NOT NULL,
  phone TEXT NOT NULL,
  address TEXT NOT NULL,
  city TEXT NOT NULL,
  is_default BOOLEAN DEFAULT FALSE,
  created_at TIMESTAMPTZ DEFAULT NOW()
);

-- 4. COUPONS TABLE
CREATE TABLE IF NOT EXISTS coupons (
  id BIGINT PRIMARY KEY,
  code TEXT UNIQUE NOT NULL,
  type TEXT NOT NULL,
  value NUMERIC(10, 2) DEFAULT 0,
  description TEXT,
  is_active BOOLEAN DEFAULT TRUE,
  expires_at TIMESTAMPTZ,
  created_at TIMESTAMPTZ DEFAULT NOW()
);

-- 5. SITE CONFIG TABLE
CREATE TABLE IF NOT EXISTS site_config (
  id INTEGER PRIMARY KEY DEFAULT 1,
  config JSONB NOT NULL DEFAULT '{}'::jsonb,
  updated_at TIMESTAMPTZ DEFAULT NOW(),
  CONSTRAINT single_row CHECK (id = 1)
);

INSERT INTO site_config (id, config)
VALUES (1, '{}'::jsonb)
ON CONFLICT (id) DO NOTHING;

-- 6. HERO SLIDES
CREATE TABLE IF NOT EXISTS hero_slides (
  id BIGINT PRIMARY KEY,
  badge TEXT,
  title TEXT,

  player TEXT,
  quote TEXT,
  description TEXT,

  sort_order INTEGER DEFAULT 0

-- 7. OFFERS
CREATE TABLE IF NOT EXISTS offers (
  id BIGINT PRIMARY KEY,
  badge TEXT,
  title TEXT,
  highlight TEXT,
  discount_text TEXT,
  description TEXT,
  coupon_code TEXT,

-- 8. FEATURES
CREATE TABLE IF NOT EXISTS features (
  id BIGINT PRIMARY KEY,
  title TEXT NOT NULL,
  description TEXT,
  icon TEXT,
  sort_order INTEGER DEFAULT 0

-- 9. CATEGORIES
CREATE TABLE IF NOT EXISTS categories (
  id BIGINT PRIMARY KEY,
  name TEXT NOT NULL,
  slug TEXT UNIQUE NOT NULL,
  description TEXT,
  image TEXT,
  sort_order INTEGER DEFAULT 0

-- 10. BRANDS
CREATE TABLE IF NOT EXISTS brands (

  name TEXT NOT NULL,

10. Adding Products

Step-by-Step

  1. Login to admin panel
  2. Go to Products
  3. Click "Add New Product"
  4. Fill in the form:
    • Product Name — e.g., "Real Madrid Home Jersey 2026/27"
    • Category — Jerseys / Football Shoes
    • Sub Category — Club / Country / Boot
    • Brand — Adidas / Nike / Puma, etc.
    • Team — Real Madrid, Barcelona, etc.
    • Type — Home / Away / Boot
    • Season — e.g., "2026/27"
    • Price, Stock, Rating
    • Images — URLs or file uploads
  5. For Jerseys: fill Kit Type, Sponsor, Player Edition, Sleeve, Collar, Fit
  6. For Boots: fill Surface, Play Style, Boot Height, Weight, etc.
  7. Add Highlights and Specifications
  8. Add Colors and Sizes
  9. Click Save

Product Variants (Home/Away/Third/GK)

To show a kit selector on the product page, add multiple products with:

  • Same Team — e.g., "Real Madrid"
  • Same Season — e.g., "2026/27"
  • Same Sub Category — e.g., "Club"
  • Different Kit Type — Home, Away, Third, Goalkeeper
💡 The system automatically groups them and shows a kit selector.

12. Deployment

Deploy to Vercel (Recommended)

  1. Push code to GitHub
  2. Go to vercel.com
  3. Click "Add New Project"
  4. Import your GitHub repository
  5. Add these Environment Variables:
    • NEXT_PUBLIC_SUPABASE_URL
    • NEXT_PUBLIC_SUPABASE_ANON_KEY
    • SUPABASE_SERVICE_ROLE_KEY
    • STRIPE_SECRET_KEY
    • NEXT_PUBLIC_STRIPE_PUBLISHABLE_KEY
    • ADMIN_EMAIL
    • ADMIN_PASSWORD
    • ADMIN_SESSION_SECRET
    • NEXT_PUBLIC_SITE_URL (e.g., https://your-app.vercel.app)
  6. Click Deploy

After Deployment

  1. Update Supabase URLs:
    • Authentication → URL Configuration
    • Site URL: https://your-domain.com
    • Redirect URLs: https://your-domain.com/**
  2. Test all features
💡 Custom Domain: Add in Vercel → Settings → Domains.

13. Troubleshooting

"Invalid API key" Error

Cause: Wrong Supabase anon key.

Fix: Copy the anon key again from Supabase Dashboard → Settings → API.

Products Not Loading

Cause: Empty Supabase tables or missing env vars.

Fix:

  1. Verify .env.local has correct Supabase keys
  2. Add products from Admin Panel
  3. Check RLS policies exist (see SQL in Section 7)

Admin Login Fails

Cause: Wrong ADMIN_EMAIL or ADMIN_PASSWORD.

Fix: Verify .env.local values and restart server.

Vercel Deployment Issues

Cause: Missing env vars in Vercel.

Fix: Add all 9 environment variables in Vercel Settings.
